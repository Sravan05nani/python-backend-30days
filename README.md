# Python Backend 30 Days

A structured learning journey from basic Python to backend systems.

Week 1 focused on core programming fundamentals:
- Variables and data types
- Conditional logic
- Loops
- Functions
- Lists and dictionaries
- Exception handling

Projects built during Week 1:

Day 1 – CLI Calculator  
Day 2 – Number Guessing Game  
Day 3 – Multiplication Table + Password Checker  
Day 4 – CLI ATM System  
Day 5 – Student Marks Manager  
Day 6 – Expense Tracker with Error Handling

Each project is written in pure Python and executed through the terminal.
The goal of this repository is to document a step-by-step journey toward building real backend systems.
